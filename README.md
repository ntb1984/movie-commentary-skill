# movie-commentary · 影视解说 Skill

给 AI agent 用的影视剧解说脚本生成器。**输入一个片名，输出一条能直接拍的解说视频方案。**

它把解说的结构固定成可执行的模板：开场钩子 → 铺垫 → 反转 → 落点，每一段都有秒数和字数预算。

## 解决什么问题

大多数人做解说，90 秒全用来复述剧情——观众早看过了，划走。
这个 skill 逼你只讲一个观点，并且把"前 3 秒必须留住人"写成硬性检查项。

## 输出什么

跑一次，你会拿到：

1. **叙事骨架**：从 5 种里选 1 种（反差神作 / 意难平 / 冷门遗珠 / 人物弧光 / 一句话反转）
2. **3 个开场钩子**：至少两种句式，标出哪个适合当封面
3. **四段脚本**：每段带秒数和字数，口语化，不用书面语
4. **素材清单**：要哪几帧画面、对应剧情位置、从哪找
5. **封面文案 3 版**：≤12 字，必须含数字或对比
6. **配音稿**：带停顿（`/`、`//`）和重音（`↑`）标记

## 用法

### 在对话里

```
用 movie-commentary 做《大话西游之大圣娶亲》
```

### 命令行算字数预算

```bash
python scripts/outline.py "大话西游" --seconds 90 --type B
```

输出：

```
| 段 | 秒数 | 字数 | 任务 |
|---|---|---|---|
| 钩子 | 0–3 | 16 | 一句反常识或一个结果，不讲背景 |
| 铺垫 | 3–27 | 131 | 只交代后面用得上的信息 |
| 反转 | 27–75 | 261 | 一个意外、一层含义、或一次视角翻转 |
| 落点 | 75–89 | 78 | 一句让人接话的话，不总结 |
```

参数：`--seconds` 目标时长（默认 90），`--type` 骨架 A–E（默认 B），`--cps` 语速字/秒（默认 5.4）。

## 安装

把整个目录放进你的 skills 目录即可，例如：

```
~/.dsh/skills/movie-commentary/
```

支持读 `SKILL.md` 的运行时（Claude Code、DSH 等）会自动识别 `name` 和 `description`。

## 目录结构

```
movie-commentary/
├── SKILL.md            # 技能说明书，AI 读这个
├── scripts/outline.py  # 按片名和时长算每段字数预算
├── README.md
└── LICENSE
```

## 适合谁

- 做影视解说短视频的（视频号 / 抖音 / 小红书 / B站）
- 想做"怀旧经典""冷门神作"这类内容，但不知道从哪切
- 已经会剪，但开头总是留不住人

## 一点说明

这个 skill 只管**结构**，不管素材版权。引用正片片段属于"适当引用"，前提是有实质性的评论和观点，且单段引用尽量不超过 30 秒。
